# Мини-приложение «Восьмой Бланк» для MAX

Мини-версия сайта blank8.pro, которая открывается внутри мессенджера MAX: главная, услуги, развёрнутый блок по маркетингу и форма заявки.

Это статический сайт без сборки — четыре файла, которые можно положить на любой хостинг с HTTPS (GitHub Pages, Vercel, Netlify, свой сервер).

## Структура

| Файл | Что в нём |
| --- | --- |
| `index.html` | Каркас, шапка, нижняя навигация, подключение MAX Bridge |
| `content.js` | **Все тексты и контакты.** Правится без знания вёрстки |
| `styles.css` | Стили, светлая и тёмная тема |
| `max-bridge.js` | Безопасная обёртка над `window.WebApp` — работает и в браузере |
| `app.js` | Экраны, навигация, отправка заявки |

## Как посмотреть локально

```bash
cd maxapp
python3 -m http.server 8080
# открыть http://localhost:8080
```

В браузере приложение работает целиком, только без функций мессенджера (кнопка «Назад» в шапке MAX, главная кнопка, данные пользователя).

## Как подключить к MAX

1. Выложить папку `maxapp` на HTTPS-адрес.
2. В MAX создать бота через `@MasterBot`, включить для него мини-приложение и указать этот адрес. По правилам платформы публикация ботов и мини-приложений доступна верифицированным юридическим лицам РФ.
3. Проверить открытие приложения из чата с ботом.

Подробности и актуальный список методов Bridge: <https://dev.max.ru/docs/webapps>.

## Куда уходят заявки

Заявки идут в MAX — боту, который открыл мини-приложение. Порядок в `app.js → sendLead()`:

1. Внутри MAX — `WebApp.sendData(json)`: бот получает событие с полями `name`, `contact`, `center`, `topic`, `message`, `user`, `sentAt`. Бот пересылает его менеджеру или в рабочий чат.
2. Открыли из браузера — текст заявки копируется в буфер и открывается чат с ботом (`CONTENT.brand.maxBot`), где пользователь вставляет его одним нажатием.
3. Если указан `CONTENT.brand.leadEndpoint`, он получает приоритет над обоими путями (POST JSON, в заголовке `X-Max-Init-Data` — подписанная строка для проверки на сервере).

Минимальный обработчик на стороне бота (Bot API MAX, псевдокод): на событие с данными из мини-приложения разобрать JSON и отправить сообщение с текстом заявки в чат менеджера (`chat_id` рабочего чата задаётся в настройках бота).

## Что заполнить перед публикацией

В `content.js`:

- `brand.phone`, `brand.email`, `brand.telegram`, `brand.max` — контакты (пустые не показываются);
- `brand.maxBot` — ссылка на бота в MAX, чтобы заявки из браузера тоже попадали в мессенджер;
- тексты разделов — сверить с сайтом.

Правила брендбука соблюдены: нет названий клиентов и скриншотов кейсов, нет сиреневого в палитре, текст без рубленых фраз.
